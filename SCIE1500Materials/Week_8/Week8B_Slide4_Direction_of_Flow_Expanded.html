Week 8B, Slide 4 — Determining the Direction of Flow

Optional extra. Same two equations as the lecture slide, laid out one at a time instead of side by side, with the differences between them called out explicitly at the end.

Why this page exists: the lecture slide puts the Prey rule and the Predator rule in two boxes side by side to save space. Reading it means constantly flicking your eyes left–right–left to check what's the same and what's different — that comparison work is separate from, and adds to, the work of understanding the maths itself. This page does the comparing for you: first each rule on its own, then a short list of exactly what differs between them.

The one idea behind both equations

Both equations have the exact same shape:

rate of change of a population  =  (that population) × (its own growth rate − the effect of the other species)

The important, slightly surprising part: whether a population is growing or shrinking depends on the size of the other population — compared with a threshold built only from its own parameters. It is never about comparing a population to itself.

Rule 1 of 2 — Prey (H)

dH/dt = H × (α − β·P)

This depends on P, the predator population — compared with the threshold α/β, which is built only from the prey's own parameters α and β.

P is below α/β dH/dt > 0 Prey increasing ↑ — not enough predators to hold them back
P is equal to α/β dH/dt = 0 Prey constant — this line is called the prey nullcline
P is above α/β dH/dt < 0 Prey decreasing ↓ — too many predators
Rule 2 of 2 — Predator (P)

dP/dt = P × (λ·H − γ)

This depends on H, the prey population — compared with the threshold γ/λ, which is built only from the predator's own parameters γ and λ.

Rows below are ordered below → equal → above, the same order as the Prey table above, so you can compare row-by-row instead of hunting for the matching line.

H is below γ/λ dP/dt < 0 Predator decreasing ↓ — not enough prey to eat
H is equal to γ/λ dP/dt = 0 Predator constant — this line is called the predator nullcline
H is above γ/λ dP/dt > 0 Predator increasing ↑ — plenty of prey to eat

Same pattern, different letters — exactly what differs

Everything below is identical in structure between the two rules. Only the four highlighted cells actually change.

Prey rule Predator rule
Own population (X in dX/dt) H P
Compares to (the other species) P H
Threshold (built from its own parameters) α/β γ/λ
Which own parameters build it α, β γ, λ
3-row increasing/constant/decreasing logic identical for both — only the labels above change
One-sentence takeaway: each species' growth rate flips sign when the other species' population crosses a threshold built from its own parameters. Prey react to predator numbers; predators react to prey numbers. Neither ever reacts to its own population size in this equation.

Quick self-check

1. If P > α/β, is the prey population increasing or decreasing? Why?

Decreasing. Predators (P) are above the prey's own threshold α/β, so dH/dt < 0 — too many predators for the prey to keep growing.

2. If H < γ/λ, is the predator population increasing or decreasing? Why?

Decreasing. Prey (H) are below the predator's own threshold γ/λ, so dP/dt < 0 — not enough food for predators to keep growing.
